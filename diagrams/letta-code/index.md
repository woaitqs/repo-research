# letta-code — interactive diagrams

Eight [Archify](https://github.com/tt-a1i/archify) diagrams. Each node carries `SRC` badges
that link to the exact lines they were drawn from, all pinned to
[`letta-ai/letta-code@4b028fa`](https://github.com/letta-ai/letta-code/tree/4b028fab07c69edaac2ddb4f7b9a43573ff20d81).

<!-- diagram-cards -->

The diagram list (titles, types, questions, pins) lives in
[`_data/studies.yml`](https://github.com/woaitqs/repo-research/blob/main/_data/studies.yml).

All eight were finalized with `archify finalize --quality showcase --repo-root <clone at the pinned commit>`
(schema validation, verified delivery, strict provenance check, headless-browser check).
The JSON specifications (Archify candidates), the gate results and a regeneration recipe are in
[`assets/letta-code/archify/`](https://github.com/woaitqs/repo-research/tree/main/assets/letta-code/archify).
