# deepagents — interactive diagrams

Eight [Archify](https://github.com/tt-a1i/archify) diagrams. Each node carries `SRC` badges
that link to the exact lines they were drawn from, all pinned to
[`langchain-ai/deepagents@16e84d9`](https://github.com/langchain-ai/deepagents/tree/16e84d927e7e13c41a10c071380c875af6a562f5).

[`_data/studies.yml`](https://github.com/woaitqs/repo-research/blob/main/_data/studies.yml).

(schema validation, verified delivery, strict provenance check, headless-browser check).

[`assets/deepagents/archify/`](https://github.com/woaitqs/repo-research/tree/main/assets/deepagents/archify).
